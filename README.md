# BuildAI — Telegram-бот

ИИ (TokenHarbor) строит постройки для Minecraft Bedrock 1.21.50.

**Игрок:** `/build замок с башнями` → бот присылает фото-предпросмотр (2 ракурса) → кнопка «Беру» → файл `.mcworld`
с единственной этой постройкой у спавна. Есть `/edit …` (доработать), `/cancel`, `/me`.

**Админ** (по Telegram ID `8859393468`): `/admin` — панель с кнопками.

| Команда | Что делает |
|---|---|
| `/off [причина]` | выключить сервис |
| `/on` | включить |
| `/update [текст]` | режим обновления (новые постройки не принимаются) |
| `/addkey <ключ>` | добавить ключ TokenHarbor (сообщение с ключом бот удаляет) |
| `/keys`, `/delkey`, `/testkeys` | список, удалить, проверить ключи |
| `/setmodel <id>` | сменить модель (по умолчанию `claude-haiku-5.5:free`) |
| `/limit <N>` | построек на человека в сутки (0 = без лимита) |
| `/ban`, `/unban`, `/banned` | блокировка по ID или @нику |
| `/broadcast <текст>` | рассылка всем (с подтверждением) |
| `/stats`, `/status`, `/backup`, `/id` | статистика, состояние, копия состояния, твой ID |

Ключи ротируются сами: если один не принят или кончился лимит, берётся следующий; админу приходит уведомление.
Админом считается только ID из `ADMIN_IDS` (ник `@cleanminder` используется для показа; по нику доступ не выдаётся,
потому что ник можно сменить или перехватить). Больше админов: `ADMIN_IDS=8859393468,123456`.

## Быстрая установка (рекомендуется)

Нужен только Python (python.org) и три вещи: токен от @BotFather, ключ TokenHarbor, аккаунт GitHub.

```
python setup.py        # Windows: двойной щелчок по start_setup.bat
```
Мастер проверит токены, сам создаст репозиторий на GitHub, загрузит туда бота, откроет Render, дождётся запуска, проверит webhook
и (по желанию) поставит пингер UptimeRobot. Вручную остаётся одно: нажать кнопку на сайте Render и вставить два значения
(Render не разрешает создавать бесплатные сервисы через API). Токены нигде не сохраняются; GitHub-токен после установки лучше удалить.

## Ручной запуск на Render (если не хотите мастер)

1. **Токен бота.** В Telegram откройте @BotFather → `/newbot` → скопируйте токен.
2. **GitHub.** Создайте репозиторий (Add file → Upload files) и загрузите туда `bot.py` и `requirements.txt`.
3. **Render.** render.com → New → **Web Service** → выберите репозиторий:
   - Runtime: **Python 3**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Instance Type: **Free**
   - Environment: `BOT_TOKEN` = токен из шага 1; `TH_KEYS` = ваш ключ TokenHarbor (можно через запятую несколько).
4. Когда сервис запустится, откройте бота с аккаунта админа и нажмите **/start**, затем **/admin**.
   Это обязательно: бот хранит копию своего состояния закреплённым файлом в вашем чате с ним.

**Важно про Render Free**
- Сервис засыпает через 15 минут без обращений; первый ответ после сна идёт около минуты. Чтобы не засыпал, добавьте
  бесплатный пингер (UptimeRobot / cron-job.org) на адрес вашего сервиса каждые 5–10 минут.
- Диск при каждом перезапуске стирается. Поэтому бот сам сохраняет ключи, режим, лимиты, баны и последние постройки
  закреплённым файлом `buildai_state.json.gz` в чате админа и восстанавливает их при старте. **Не удаляйте и не пересылайте
  это сообщение**: внутри API-ключи. Отключить копию: `TG_BACKUP=0` (тогда ключи берутся из `TH_KEYS`).

## Запуск на своём компьютере или сервере

```
pip install -r requirements.txt
BOT_TOKEN=123:ABC TH_KEYS=ваш_ключ python bot.py        # Windows: set BOT_TOKEN=... затем python bot.py
python bot.py --selftest                                # проверка без Telegram: создаст selftest.mcworld и картинку
```
Без `WEBHOOK_URL` бот работает через long polling и ничего открывать наружу не нужно.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | токен бота (обязательно) |
| `TH_KEYS` | — | ключи TokenHarbor через запятую (можно добавлять и командой `/addkey`) |
| `ADMIN_IDS` | `8859393468` | ID админов через запятую |
| `TH_MODEL` | `claude-haiku-5.5:free` | модель |
| `DAILY_LIMIT` | `5` | построек на человека в сутки (меняется `/limit`) |
| `COOLDOWN_SEC` | `20` | пауза между построками одного человека |
| `WORKERS` / `MAX_QUEUE` | `2` / `8` | сколько строится одновременно / сколько ждёт |
| `UTC_OFFSET_H` | `5` | часовой пояс для «суток» (Алматы = 5) |
| `TG_BACKUP` | `1` | копия состояния в Telegram |
| `WEBHOOK_URL` | авто на Render | публичный адрес; без него — long polling |
| `DATA_DIR` | `./data` | где лежит `state.json` |

## Как устроен мир

Плоский мир (трава на y = −61), творческий режим, день без смены суток, мобы выключены. Игрок появляется в точке (0, −60, 0),
постройка стоит в 8 блоках на восток, по оси Z по центру. Есть и запасная кнопка `.mcstructure` — для импорта через блок структуры.

## Что проверено

Движок построек даёт те же блоки, что `BuildAI_v9.html` (сверено на случайных наборах операций). Файл мира открывается настоящим
LevelDB и читается независимым декодером чанков. Бот прогнан целиком на тестовом Telegram: команды, кнопки, лимиты, режимы,
ротация ключей, восстановление состояния, webhook. **Не проверено:** открытие `.mcworld` в самом Minecraft и работа с живыми
серверами Telegram и TokenHarbor — это стоит проверить первым делом. Если мир не откроется, используйте `.mcstructure`
и сообщите об ошибке.
